Tic-Tac-Toe AI
==============

This game uses Flask and a minimax AI. You play as X against the AI as O.

Requirements: Python 3 and Flask.

To run:
1. Open a terminal in this folder.
2. Install Flask: python -m pip install flask
3. Run: python app.py
4. Open http://127.0.0.1:5000 in your browser.
5. Press Ctrl+C in the terminal to stop the server.

The interface uses HTML forms and CSS.
